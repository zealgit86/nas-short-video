# 部署说明

## 映射自己的 NAS 路径

编辑 `.env` 的 `LIBRARY_PATH`、`UPLOAD_PATH` 和 `DATA_PATH`。容器内逻辑路径保持 `/srv/videos/library`、`/srv/videos/mobile` 和 `/srv/appdata`。

群晖 Container Manager 可以使用本仓库 Compose 创建项目。首次构建需联网，硬件较慢时需要较长时间。当前未发布预构建镜像。

视频目录映射为可写时支持上传和永久删除；仅观看使用只读挂载。不要将整个 NAS 根目录挂入容器。启动前确认宿主机的目录确实存在。

## 更新与回退

更新前备份 `data/`，保留上一版镜像标签，停止服务后再更新代码并重新构建。回退使用上一版镜像及匹配的数据备份。原视频应独立备份；人物“移出”和“转移”只改变归属，删除按钮会删除原文件。

## 手机与 HTTPS

手机和 NAS 处于同一个 LAN 或 VPN，`PUBLIC_URL` 必须是手机能访问的实际地址。默认 Compose 只映射 8765 端口，HTTPS 反向代理需另行配置；本项目不会自动配置公网访问。

## 资源使用

缩略图首次被访问时使用低优先级、单线程 FFmpeg 生成，随后读缓存；时长与大小由低优先级 ffprobe 获取并缓存。不会全量转码原视频。大型目录刷新索引需要遍历文件系统，耗时依磁盘、数量及目录结构而变化。
